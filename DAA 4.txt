## Theory

Fractional Knapsack is a Greedy Algorithm used to maximize the total profit within a given knapsack capacity. Each item has a weight and a profit. We can take either the whole item or a fraction of it.

The greedy method selects items according to their profit-to-weight ratio in decreasing order. Items with a higher ratio are selected first until the knapsack is full.

## C++ Program

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Item {
    int weight, profit;
};

bool compare(Item a, Item b) {
    return (double)a.profit / a.weight >
           (double)b.profit / b.weight;
}

int main() {
    int n, capacity;
    cout << "Enter number of items: ";
    cin >> n;

    Item items[n];

    for (int i = 0; i < n; i++) {
        cout << "Enter weight and profit of item "
             << i + 1 << ": ";
        cin >> items[i].weight >> items[i].profit;
    }

    cout << "Enter knapsack capacity: ";
    cin >> capacity;

    sort(items, items + n, compare);

    double totalProfit = 0;

    for (int i = 0; i < n; i++) {
        if (capacity == 0)
            break;

        if (items[i].weight <= capacity) {
            capacity -= items[i].weight;
            totalProfit += items[i].profit;
        }
        else {
            totalProfit +=
                (double)items[i].profit / items[i].weight
                * capacity;

            capacity = 0;
        }
    }

    cout << "\nMaximum Profit: " << totalProfit;

    return 0;
}
```

## Sample Input

```text
Enter number of items: 3
Enter weight and profit of item 1: 10 60
Enter weight and profit of item 2: 20 100
Enter weight and profit of item 3: 30 120
Enter knapsack capacity: 50
```

## Output

```text
Maximum Profit: 240
```

## Complexity Analysis

- **Time Complexity:** O(n log n), because items are sorted according to their profit-to-weight ratio.
- **Space Complexity:** O(1) auxiliary space for the greedy selection, excluding the input array and sorting implementation.

**Greedy Strategy:** Calculate the profit-to-weight ratio of each item, sort items in decreasing order, and select the highest-ratio items first. If an item cannot fit completely, take only the required fraction.
